# Paliwo PF

Dziennik tankowań i kosztów eksploatacji samochodu (RA-STER). Jeden plik
`index.html` (frontend) + Google Apps Script (`apps-script/Code.gs`) jako
backend zapisujący dane w Arkuszu Google + GitHub Pages jako hosting.

Backend/instrukcja wdrożenia: patrz `apps-script/Code.gs` i rozmowa z Claude.
